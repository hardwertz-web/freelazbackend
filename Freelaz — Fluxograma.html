Freelaz — Fluxograma completo das telas

Do cadastro até o repasse financeiro. Role na horizontal se precisar — o diagrama é largo de propósito.

flowchart TD
  A["Cadastro único
CPF ou CNPJ"] --> B["Dados básicos
nome/razão social, email, telefone"]
  B --> C{"O que você
quer fazer?"}
  C -->|Oferecer serviços| D["Onboarding profissional
categorias, portfólio"]
  C -->|Contratar| E["Onboarding contratante"]
  C -->|Os dois| D
  C -->|Os dois| E
  D --> F["Verificação: documento + selfie"]
  E --> G["Verificação leve
email/telefone"]
  F --> H["Home"]
  G --> H

  H --> H1["Feed de vagas freelance
perto de você"]
  H --> H2["Abas: Freelance / CLT / Prestadoras"]
  H --> H3{"Toggle de modo
(se os 2 papéis ativos)"}

  H3 -->|Modo profissional| H1
  H3 -->|Modo contratante| V2["Publicar vaga"]

  H1 --> V1["Detalhe da vaga"]
  V1 --> V4["Candidatar-se"]
  V1 --> V5p["Me contrate
(perfil do profissional)"]

  V2 --> V2a{"Publicar com
urgência? R$10"}
  V2a -->|Sim| V2b["Checkout do boost"]
  V2a -->|Não| V3["Vaga publicada
(ABERTA)"]
  V2b --> V3
  V3 --> V4

  V5p --> V5["Gera vaga PRIVADA
só para esse profissional"]
  V5 --> V5n{"Profissional decide"}
  V5n -->|Aceita| V6
  V5n -->|Recusa| V5end["Vaga privada encerrada"]
  V5n -->|Contraproposta| V5c["Nova oferta de valor"]
  V5c --> V5n2{"Empresa decide"}
  V5n2 -->|Aceita| V6
  V5n2 -->|Recusa/nova oferta| V5c
  V5n2 -->|Desiste| V5end

  V4 --> V6["Lista de candidaturas"]

um candidato"}

(nunca recusados de vez)"]
  V7 -->|Ninguém selecionado| V3

  V8 --> P1["Checkout Mercado Pago"]
  P1 --> P2{"Pagamento
aprovado?"}
  P2 -->|Não| V3
  P2 -->|Sim| P3["Vaga some do marketplace

  P3 --> P4["Chat desbloqueia"]

  X4 -->|Sim| X5["Serviço concluído"]
  X4 -->|Desacordo no chat| X6["Cancelamento

  X2 -->|Profissional desiste| X6

  X5 --> X7["2h depois:
